Kể từ Go 1.21, các bản tải xuống bộ công cụ nhị phân của Go được cung cấp bởi go.dev/dl/ có thể được tái tạo và xác minh bởi bất kỳ ai, trên bất kỳ nền tảng nào, bằng cách sử dụng golang.org/x/build/cmd/gorebuild. Để biết thêm chi tiết, xem bài đăng trên blog “Bộ công cụ Go có thể tái tạo và xác minh hoàn hảo.”

Trang này được cập nhật hằng ngày với kết quả chạy gorebuild trong một máy ảo Ubuntu, sử dụng tập lệnh sau: 

apt-get update &&
apt-get -y install software-properties-common &&
add-apt-repository universe &&
apt-get -y install golang-go git msitools &&
go run golang.org/x/build/cmd/gorebuild@latest -p=4

Việc cài đặt git cho phép gorebuild lấy mã nguồn Go từ kho lưu trữ Git chính thức của nó, và việc cài đặt msitools cho phép gorebuild kiểm tra nội dung của tệp cài đặt MSI của Windows. -p=4 có nghĩa là chạy tối đa bốn bản dựng song song.
