Chủ đề này mô tả cách cài đặt nhiều phiên bản Go trên cùng một máy, cũng như cách gỡ cài đặt Go.

Đối với nội dung khác về việc cài đặt, bạn có thể quan tâm đến:

  • Tải xuống và cài đặt -- Cách đơn giản nhất để cài đặt và bắt đầu chạy.
  • Cài đặt Go từ mã nguồn -- Cách lấy mã nguồn, tự xây dựng trên máy của bạn và chạy chúng.

Cài đặt nhiều phiên bản Go

Bạn có thể cài đặt nhiều phiên bản Go trên cùng một máy. Ví dụ, bạn có thể muốn kiểm thử mã của mình trên nhiều phiên bản Go. Để xem danh sách các phiên bản có thể cài đặt theo cách này, hãy xem trang tải xuống.

Lưu ý: Để cài đặt bằng phương pháp được mô tả ở đây, bạn cần phải cài đặt git.

Để cài đặt các phiên bản Go bổ sung, hãy chạy lệnh go install, chỉ định vị trí tải xuống của phiên bản bạn muốn cài đặt. Ví dụ sau minh họa với phiên bản 1.10.7: 

$ go install golang.org/dl/go1.10.7@latest
$ go1.10.7 download

Để chạy các lệnh go với phiên bản mới được tải xuống, hãy thêm số phiên bản vào lệnh go như sau: 

$ go1.10.7 version
go version go1.10.7 linux/amd64

Khi bạn đã cài đặt nhiều phiên bản, bạn có thể tìm vị trí cài đặt của từng phiên bản bằng cách xem giá trị GOROOT của phiên bản đó. Ví dụ, hãy chạy một lệnh như sau: 

$ go1.10.7 env GOROOT

Để gỡ cài đặt một phiên bản đã tải xuống, chỉ cần xóa thư mục được chỉ định bởi biến môi trường GOROOT của phiên bản đó và binary goX.Y.Z.

Gỡ cài đặt Go

Bạn có thể xóa Go khỏi hệ thống bằng các bước được mô tả trong chủ đề này.

Xóa cấu hình và dữ liệu của người dùng

Go lưu cấu hình người dùng trong thư mục go bên trong thư mục cấu hình người dùng, như được trả về bởi os.UserConfigDir. Bạn cũng có thể tìm thấy thư mục này là thư mục chứa tệp cấu hình được trả về bởi go env GOENV.

Go lưu các phần tạo tác xây dựng trung gian trong thư mục được trả về bởi go env GOCACHE. Bạn có thể xóa chúng bằng go clean -cache.

Go lưu các dependency đã tải xuống trong thư mục được trả về bởi go env GOMODCACHE. Bạn có thể xóa chúng bằng go clean -modcache.

Go lưu các binary được cài đặt bằng go install trong thư mục bin của Go, như được trả về bởi go env GOBIN (mặc định là $HOME/go/bin). Bạn có thể xóa chúng bằng cách xóa thư mục đó. Nếu bạn đã thêm thư mục này vào biến môi trường PATH, bạn cũng nên xóa nó.

  1. Xóa /usr/local/go.

    Đây là thư mục cài đặt mặc định.

  2. Xóa /usr/local/go khỏi biến môi trường PATH của bạn.

    Trên Linux và FreeBSD, hãy chỉnh sửa /etc/profile hoặc $HOME/.profile.

  3. Nếu bạn đã tự thêm thư mục bin của Go (thường là $HOME/go/bin) vào cấu hình shell của mình, ví dụ bằng cách thêm export PATH="$PATH:$(go env GOPATH)/bin", hãy xóa mục đó.

  4. Khởi động lại mọi phiên terminal đang mở để các thay đổi có hiệu lực.

  1. Xóa /usr/local/go.

    Đây là thư mục cài đặt mặc định.

  2. Xóa /usr/local/go khỏi biến môi trường PATH của bạn.

    Nếu bạn cài đặt Go bằng gói macOS, hãy thực hiện việc này bằng cách xóa tệp /etc/paths.d/go.

  3. Nếu bạn đã tự thêm thư mục bin của Go (thường là $HOME/go/bin) vào cấu hình shell của mình, ví dụ bằng cách thêm export PATH="$PATH:$(go env GOPATH)/bin", hãy xóa mục đó.

  4. Khởi động lại mọi phiên terminal đang mở để các thay đổi có hiệu lực.

Bạn có thể gỡ Go khỏi Windows bằng một trong các phương pháp sau:

Phương pháp 1: Control Panel (Đơn giản nhất)

  1. Mở Control Panel và nhấp đúp vào Add/Remove Programs.
  2. Chọn Go Programming Language, nhấp Uninstall, sau đó làm theo hướng dẫn.

Phương pháp 2: Dòng lệnh

Gỡ cài đặt bằng dòng lệnh bằng cách chạy lệnh sau:

msiexec /x go{{version}}.windows-{{cpu-arch}}.msi /q

Lưu ý: Sử dụng quy trình này sẽ tự động xóa các biến môi trường Windows được tạo bởi lần cài đặt ban đầu.
